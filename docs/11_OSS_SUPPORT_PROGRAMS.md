# 11. OSS支援制度と申請準備

> **確認日**: 2026-09-15  
> **対象**: SEO Analyzerの継続開発、レビュー、セキュリティ監査、公開運用

SEO Analyzerは、個人の趣味として開発・運用する公開オープンソースプロジェクトです。運営費の一部を広告収益でまかなうことを想定しています。OSS支援制度への申請だけを目的とせず、SEO、検索パフォーマンス、Web品質、Google公式APIの情報を一つの画面で確認できる実用的な道具として継続運用します。

## 1. OpenAI: Codex for Open Source

[Codex for Open Source](https://openai.com/form/codex-for-oss/) は、活動中のオープンソースプロジェクトの主要・コアメンテナーを対象とする制度です。公式案内では、選考対象に6か月のChatGPT Pro、条件付きのCodex Security、保守自動化などに使えるAPIクレジットが含まれます。

申請時に求められる主な情報:

- 公開GitHubプロフィールと公開リポジトリ
- 主要またはコアメンテナーとしての役割
- 利用実績、普及状況、エコシステム上の重要性
- PRレビュー、Issue整理、リリース、セキュリティ維持などの継続的な活動
- OpenAI Organization ID
- APIクレジットの具体的な利用計画

## 2. OpenAI: Codex open source fund

[Codex open source fund](https://openai.com/form/codex-open-source-fund/) は、Codex CLIとOpenAIモデルを利用するOSSプロジェクトに対し、最大25,000米ドル相当のAPIクレジット助成を案内しています。審査は随時行われます。

## 3. Anthropic: Claude for Open Source

[Claude for Open Source](https://claude.com/contact-sales/claude-for-oss) は、条件を満たすOSSメンテナーや貢献者へ6か月のClaude Max 20xを提供する制度です。公開されている目安には依存リポジトリ数、月間ダウンロード数、外部リポジトリへのマージ済みPR数、外部貢献者数、OpenSSF criticality scoreなどがあります。

## 4. SEO Analyzerで整備する証拠

- 公開サイトと再現可能なセットアップ手順
- Wikiに整理した設計、API、運用、セキュリティ資料
- Issue、Pull Request、リリース履歴
- 実ユーザー数、利用回数、継続利用率などの公開可能な集計
- 外部コントリビューター向けの `CONTRIBUTING.md` とIssueテンプレート
- Codexを使ったPRレビュー、障害修正、ドキュメント更新の具体例
- APIクレジットを使う機能と、OSS保守へ還元する成果の説明

申請条件や提供内容は変更される可能性があるため、申請時には各公式ページの最新内容を確認します。
